## 3. TECH STACK & MOTION ENGINEERING RULES

- **Packages:** React, TypeScript, Vite, Tailwind CSS, `framer-motion`, `lenis`, `three`, `@types/three`, `lucide-react` (small UI utility icons like arrows/search/sun/moon ONLY—never use Lucide icons inside showcase motion boxes or unit cards).
- **Motion Constants (`src/lib/motion.ts`):**
  - `EASE_EXPO = [0.22, 1, 0.36, 1]`
  - `SPRING_SNAPPY = { type: "spring", stiffness: 380, damping: 32, mass: 0.85 }`
  - `SPRING_SOFT = { type: "spring", stiffness: 220, damping: 28, mass: 1 }`
- **Scroll Architecture:**
  - Initialize `Lenis` smooth scrolling cleanly at root level with smooth wheel inertia (`lerp: 0.09`), properly destroyed on unmount.
  - Use `framer-motion` (`useScroll`, `useTransform`, `useSpring`, `useVelocity`, `AnimatePresence`, `layoutId`) for all UI choreography and scroll-linked perspective transforms so React never clashes with external DOM mutation libraries.
- **Performance & Accessibility:**
  - WebGL & `<canvas>` loops MUST cap pixel ratio at `Math.min(window.devicePixelRatio || 1, 2)` (`<= 1.5` on screens `< 768px`), use clamped `deltaTime <= 0.05` so 120Hz displays run at normal speed, pause via `IntersectionObserver` when scrolled offscreen, and dispose all geometries/materials/renderers on unmount.
  - Animate ONLY GPU-composited properties (`transform`, `opacity`, `clip-path`, SVG `pathLength`/`strokeDashoffset`).
  - Every `whileInView` reveal MUST set `viewport={{ once: true, amount: 0.15 }}`.
  - Respect `useReducedMotion()` globally: freeze continuous shader/canvas motion cleanly to a poised static frame and disable scroll-skew/parallax transforms when active.
